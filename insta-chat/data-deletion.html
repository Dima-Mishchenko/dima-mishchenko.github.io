User Data Deletion Instructions

Last updated: November 20, 2026

The Debloat 30 Instagram Assistant (operated by Soldatenko LLC for @anastasiia.debloat) stores only minimal, temporary metadata (Instagram-scoped user ID, username, recent message snippet, and reply status) needed to deliver requested guide links and avoid duplicate replies.

How to Request Deletion of Your Data

  1. Email us: Send a request to anastasiia@debloat.space with your Instagram username, and we will delete all matching data immediately (and within 30 days at most).
  2. Via Instagram Settings: Remove the app connection under Instagram Settings → Website permissions → Apps and websites.
  3. Via Direct Message: Send delete my data in a DM to @anastasiia.debloat.

Automated Meta Data Deletion Callback

When you remove app permissions via Facebook or Instagram Settings, Meta automatically notifies our deletion callback endpoint, which purges any stored logs associated with your Instagram-scoped user ID and returns a confirmation code.
