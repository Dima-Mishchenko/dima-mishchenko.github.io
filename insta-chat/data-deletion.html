User Data Deletion Instructions

Last updated: November 20, 2026

The Anastasiia Debloat Instagram Assistant stores only minimal, temporary metadata (Instagram-scoped user ID, username, recent message snippet, and reply status) needed to deliver requested guide links and avoid duplicate replies.

How to Request Deletion of Your Data

  1. Via Instagram: Send a Direct Message saying delete my data to @anastasiia.debloat, or remove the app connection in your Instagram Settings under Settings → Website permissions → Apps and websites.
  2. Via Website: Contact us through https://www.debloat.space/ with your Instagram username so we can purge any matching log entries immediately.

Automated Meta Data Deletion Callback

When you remove app permissions via Facebook/Instagram Settings, Meta automatically notifies our deletion callback endpoint, which removes any stored logs associated with your Instagram-scoped ID and provides a confirmation code.
